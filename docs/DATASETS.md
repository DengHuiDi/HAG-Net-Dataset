# Datasets

Dataset A contains 6,373 images: 4,734 training and 1,639 validation images. Its YOLO annotations contain 16,417 fire boxes and 9,774 smoke boxes (26,191 total). There are 490 empty-label images. Dataset A is not redistributed here.

FSD-1902 contains 1,902 RGB images and 7,904 boxes: 2,768 fire and 5,136 smoke. The fixed split contains 1,332 training, 380 validation, and 190 test images. Extract `FSD-1902.zip` in the repository root before using the supplied lists. Its source dataset is FLAME 2 (IEEE DataPort DOI: 10.21227/swyw-6j78).

D-Fire is not redistributed. Download it from its official source and update `configs/dfire.yaml`.
