# Datasets

Dataset A contains 6,373 images: 4,734 training and 1,639 validation images. Its YOLO annotations contain 16,417 fire boxes and 9,774 smoke boxes (26,191 total). There are 490 empty-label images. The fixed [Dataset A split manifest](../splits/dataset_a/dataset_a_manifest.csv) provides image IDs, relative paths, split membership, and SHA-256 checksums; [field definitions and distribution scope](../splits/dataset_a/README.md) are provided alongside it. Dataset A images and labels are not redistributed here.

FSD-1902 contains 1,902 selected RGB images and 7,904 team-added boxes: 2,768 fire and 5,136 smoke. The fixed split contains 1,332 training, 380 validation, and 190 test image IDs. The original imagery comes from Hopkins et al., *FLAME 2: Fire detection and modeLing: Aerial Multi-spectral imagE dataset* ([official IEEE DataPort source](https://doi.org/10.21227/swyw-6j78)). Obtain source images there under the provider's applicable terms. The [annotations-only package](../annotations/fsd1902/FSD-1902-annotations-only.zip) contains the YOLO labels, fixed lists, [image-name mapping/status](../annotations/fsd1902/image_mapping.jsonl), and [assembly instructions](../annotations/fsd1902/README.md); it contains no images, videos, or previews. The original FLAME 2 filename-to-working-name map is unavailable, so automatic reconstruction from the official download is not claimed. The [archived DataPort page](https://par.nsf.gov/servlets/purl/10412065) lists “Creative Commons Attribution,” but a specific version and complete license text have not been verified. The original-image license is separate from the repository code license.

D-Fire is not redistributed. Download it from its official source and update `configs/dfire.yaml`.
