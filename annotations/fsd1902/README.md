# FSD-1902 annotations and fixed split (no source images)

The original RGB imagery used for FSD-1902 comes from Hopkins et al., *FLAME 2: Fire detection and modeLing: Aerial Multi-spectral imagE dataset*, IEEE DataPort, DOI [10.21227/swyw-6j78](https://doi.org/10.21227/swyw-6j78). Obtain the source images from that official record under the provider's applicable terms. This package contains **no images, videos, or previews**. The archived DataPort page lists “Creative Commons Attribution”; the exact license version and legal-text URL have not been verified from the original download.

The team selected 1,902 RGB images, added YOLO fire/smoke bounding-box labels, and defined a fixed 1,332/380/190 train/validation/test split. Class 0 is fire and class 1 is smoke. `dataset/labels/` contains 1,902 TXT files, including one empty file. `splits/` contains the unchanged fixed image lists. `image_mapping.jsonl` gives the working image filename, matching label file, split, and any filename-derived video/frame hints.

To assemble a local working dataset, obtain the FLAME 2 images from the official source and establish a verified one-to-one match between each original source image and the `image_filename_in_FSD1902` in `image_mapping.jsonl`. Place the matched images at the listed `image_path_expected_after_user_assembly`; keep the supplied labels at `dataset/labels/` and use the fixed split lists. **The present files do not contain a verified original-FLAME-2-to-FSD-1902 rename map.** All `flame2_original_filename` and `flame2_original_frame_id` values are null and `original_to_annotation_mapping_status` is `unverified`. Do not guess matches from similar filenames or frame numbers. Until a mapping is recovered and checked, this package alone cannot reconstruct the full experimental image set from the official download.

The source-image license is separate from this repository's code license. Neither the code license nor this annotations-only package grants additional rights to the original images. Processing steps not documented by existing records are not asserted here.
